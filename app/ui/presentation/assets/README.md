# Live-demo assets

`demo_results/patchcore/` contains two curated four-panel inspection examples for each of the 15 MVTec AD categories. Each panel shows the source image, dataset mask, anomaly evidence, and thresholded decision. The Streamlit live demo uses these images; the static presentation pages come from `docs/latex/latex_beamer_presentation/main.pdf`.

The source figures needed to rebuild the PDF live under `docs/latex/latex_beamer_presentation/figures/`, not here. MVTec AD images remain subject to the terms in `LICENSE-DATA.md`.
